# 费曼学习法卡片｜合集规划

> 副本，原文是 Claude Docs 文档 https://claude.ai/artifact/VQGAokE3Bz8KggeR4pUU2j（2026-10-23，rev 14）。两边不一致时以原文为准，改完原文后同步这里。

## 总体思路：一棵永远在长的知识树

合集不设总数，也不设收尾集。它是一棵树：01 三观是根，往上长出六根主干，每根主干分出一级知识点，每个知识点又由一层层更细的下级卡片支撑，可以一直往下长。

每张卡片都知道自己挂在哪里：它的上级是谁，它支撑着什么，它和别的枝条有什么关联。一个概念讲不透时，就是它该长出下级卡片的时候。这正好就是费曼学习法的第三步：哪里卡住，就回去补哪里。

六根主干是起点，不是限制：以后发现新领域，可以再长第七根。

> 用户的明确要求（2026-10-23）：合集必须是树状、发散、开放的结构，没有终点；每个知识点由多层下级卡片支撑。不设固定集数、不分季、没有大结局。第一版「40 张 + 收官集」的方案被否决。

## 生长规则

**两套编号并存。** 发布号按发布顺序一直往上数（01、02、03…），没有上限；树码标明卡片在树上的位置。树码用字母加数字：主干是 A–F，一级知识点是 A3，它的下级是 A3.1，再往下是 A3.1.2。封面和标题两个都写，例如「费曼卡片 07｜A3 概率思维」。

| 树码 | 层级 | 例子 |
|---|---|---|
| 根 | 看世界的镜片 | 01 三观 |
| A | 主干 | 怎么想（主干卡：02 哲学） |
| A3 | 一级知识点 | 概率思维 |
| A3.1 | 二级卡片 | 期望值 |
| A3.1.1 | 三级卡片 | 为什么买彩票长期一定亏 |

**下级卡片从哪里长出来**：

- **卡住的地方**：讲一张卡时用到了一个还没讲过的概念，就把它记为这张卡的下级。
- **评论区的追问**：观众问「那……呢？」，就是一张现成的下级卡片。
- **生活里的领悟**：你自己的新理解，找到它支撑的知识点挂上去。

**枝条之间会互连。** 一张卡只有一个上级，但可以「连向」别的枝条。比如 B3 复利挂在「世界怎么运转」下面，同时连向 C4 习惯和 E2 金钱。片尾的「推荐接着看」就从上级、下级和连向里挑。

## 发布方式：先广后深，哪里有人问就往哪里长

不分季，也不设收尾。前期先让六根主干都冒出头，让观众看到树的全貌；之后哪根枝条播放好、评论追问多，就顺着它往下挖一层。每 8 张卡左右，插一张「树长到哪了」的长势图，把已发的卡片挂回树上。

|---|---|---|---|
| 03 | A1 | 费曼学习法 | 解释合集名字和这棵树怎么长 |
| 04 | C3 | 多巴胺与注意力 | 在抖音讲「刷停不下来」，最容易共鸣 |
| 05 | A3 | 概率思维 | 硬核但好懂，生活例子多 |
| 06 | A3.1 | 期望值 | 第一次示范「往下长一层」 |
| 07 | E2 | 金钱 | 从期望值连向金钱，示范枝条互连 |

## 每集统一格式

沿用 02 的做法：竖屏约 1 分 30 秒到 2 分钟，同一男声配音，本地模型配乐。每集按费曼四步走：

1. **钩子问题**（前 3 秒）：一个观众答不上来的生活问题。
2. **大白话讲懂**：一个生活例子，不用术语。
3. **卡住的地方**：常见误解；这里也是下级卡片长出来的地方。
4. **一句话卡片**：定格一张卡片画面，写上树码和本集的一句话定义。

片尾加一个小小的树枝动画：这张卡亮起来，标出它的上级和下一张。再留一个今晚就能做的小动作，和一句「你卡在哪里，评论区告诉我，下一张卡可能就为你长」。
