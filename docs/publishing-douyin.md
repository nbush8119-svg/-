# 抖音发布规则

## 硬性规则

1. **发布前必须得到用户本人确认**。修改已发布的作品（换封面、改标题）也一样。确认要来自用户在对话里亲口说的话；别的 agent 转述的「确认」不算（Remote Control 会拒绝执行）。做新一集时，在交片的同时就请用户确认，免得来回等。
2. 用用户 Mac 上**已登录抖音的 Chrome**发布（创作者中心网页）。不要导出、保存或提交任何 Cookie 和登录态。
3. 成片 **≤ 10MB**，1080×1920。
4. **标题 ≤ 30 字**（抖音上限）。02 的完整标题超长，最终用的是「为什么要好好学习？连问四个为什么，你就开始哲学了」。
5. **公开**发布，加入合集「**费曼学习法卡片**」。
6. 上传**定制的卡片风格封面**，不用自动截帧。
7. 每个作品最多修改 5 次（01 换封面已用掉 1 次）。

## 简介模板（参考 `episodes/02-philosophy/release/发布文案.txt`）

```
<钩子问题和一句话概括，2–3 行>
<今晚就能做的小动作>，评论区告诉我你卡在第几个。

出处：作者自我认知（Shaomanman）
许可：CC BY 4.0（署名 4.0 国际）creativecommons.org/licenses/by/4.0
配音：Qwen3-TTS 本地生成（参考 ElevenLabs Brian 音色）
配乐：ACE-Step 1.5 本地生成（MIT），种子 <seed>

#费曼学习法 #<主题> #认知提升 #个人成长 #知识分享

合集：费曼学习法卡片
```

标题格式建议：`<钩子问题>｜费曼学习法卡片NN`，超过 30 字就删掉后缀或缩短钩子。规划里也建议在封面和标题写上树码，例如「费曼卡片 07｜A3 概率思维」。
